# 구매 문의 이메일 자동 발송 설정 (약 10분)

## 1. Google Apps Script 만들기
1. `https://script.google.com/`에서 **새 프로젝트** 생성. 반드시 `rkdwnsgh2002@gmail.com` 계정으로 로그인.
2. `GoogleAppsScript/Code.gs` 전체를 복사하여 `Code.gs`에 붙여넣고 저장.
3. 상단 **배포 → 새 배포 → 유형: 웹 앱** 선택.
4. **다음 사용자 인증 정보로 실행: 나**, **액세스 권한: 모든 사용자**로 설정. 권한 요청 화면에서 본인 계정으로 승인. 공개 웹 앱은 스팸 및 악용 위험이 있으므로 접수량을 주기적으로 점검하세요.
5. 배포된 **웹 앱 URL (`https://script.google.com/macros/s/.../exec`)**을 복사.

## 2. 홈페이지와 연결
1. GitHub에 업로드할 `config.js`의 `inquiryWebAppUrl`에 위 URL을 붙여넣기.
2. `Code.gs`의 `ALLOWED_ORIGIN`은 기본 `https://kangjunho.github.io`이며, 사용자 정의 도메인을 사용하면 변경 후 **새 버전 배포** 필요.
3. GitHub 저장소 `kangjunho/Sinnong-Farm`에 이 ZIP 압축을 푼 **파일과 assets 폴더 전체** 업로드.
4. `https://kangjunho.github.io/Sinnong-Farm/contact.html`에서 실제 테스트 문의를 한 번 전송하고 Gmail 수신함 및 스팸함 확인.
5. Apps Script에서 수정한 뒤에는 **배포 관리 → 편집 → 새 버전**으로 다시 배포.

## 3. Google Sheets 기록 (선택)
1. Google Sheets에서 빈 스프레드시트를 만들고 URL의 `/d/`와 `/edit` 사이 ID를 복사.
2. Apps Script **프로젝트 설정 → 스크립트 속성**에 `SHEET_ID`라는 이름으로 ID 저장.
3. 필요하면 Apps Script의 새 배포 버전에서 추가 권한을 승인하고 테스트. 시트 기록은 선택 사항이며 메일 발송 성공과 별개입니다.

## 4. 운영 시 주의
- GitHub에는 Gmail 비밀번호, API 키, Google Sheet ID 등 비밀 정보를 올리지 마세요. `config.js`의 웹 앱 URL은 공개되므로 비밀 키로 간주하면 안 됩니다.
- 웹 앱은 누구나 호출할 수 있습니다. 현재는 기본 입력 검증 및 숨김 필드만 포함하며 강력한 봇 방어·요청 빈도 제한은 구현되지 않았습니다. 공개 운영 전 reCAPTCHA/Turnstile 검증을 추가하는 것이 좋습니다.
- 개인정보 보유기간(예시 3개월)은 실제 운영 정책에 맞춰 확정하고, Gmail·Sheets에서도 해당 기간 후 삭제하는 절차가 필요합니다.
- Google Apps Script의 일일 메일 발송 한도 및 서비스 장애 가능성이 있습니다.
- 이 ZIP을 업로드하는 것만으로 자동 메일이 발송되지는 않습니다. 반드시 웹 앱 배포 및 `config.js` URL 설정이 필요합니다.

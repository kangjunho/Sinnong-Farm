# 신농산삼약초농원 공식 홈페이지

지리산 함양 마적대 · 생산자 강재두 · 산양삼 원물 3~4년근 / 5~6년근 / 7~8년근 / 9~10년근 / 11년근 이상.

## GitHub 업로드 (중요)
1. 이 ZIP 파일의 압축을 풉니다.
2. **Sinnong-Farm-GitHub-Upload 폴더 자체가 아닌, 그 안의 파일과 assets 폴더 전체**를 선택합니다.
3. https://github.com/kangjunho/Sinnong-Farm 에서 Add file → Upload files 로 업로드하고 Commit changes 합니다.
4. 저장소 첫 화면에 `index.html`, `style.css`, `script.js`, `config.js`, `assets/`가 보여야 합니다.
5. Settings → Pages 에서 main / (root) 배포가 활성화되어 있으면 자동 갱신됩니다.
6. https://kangjunho.github.io/Sinnong-Farm/ 에서 확인합니다.

## 설정
`config.js`의 `phone`에 실제 문의 번호, `ga4MeasurementId`에 GA4 측정 ID(G-...)를 입력합니다. GA4는 방문자가 분석 쿠키에 동의한 경우에만 로드됩니다. 실제 운영 전 개인정보처리방침을 마련하고 관련 고지를 검토하세요.

## 이미지
`assets/spring.webp`, `assets/autumn.webp`는 실제 농장 풍경 사진입니다. 여름과 겨울은 실제 촬영 사진이 없어서 안내 문구로 표시합니다. 나머지 사진도 제공받은 농장 사진입니다. 연근별 상품 사진은 아직 확보되지 않아 공통 재배지 사진으로 표시합니다.

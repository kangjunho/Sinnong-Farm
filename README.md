# 신농산삼약초농원 홈페이지

GitHub Pages용 정적 웹사이트입니다.

## 배포
1. GitHub에서 새 public repository 생성 (예: `sinnong-farm`).
2. 이 ZIP 파일의 압축을 풀어 `index.html`, `style.css`, `script.js`를 저장소 루트에 업로드합니다.
3. Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.
4. 배포 주소: `https://<GitHub사용자명>.github.io/sinnong-farm/`.

## 수정
- 소개 및 링크: `index.html`
- 상품 연근: `script.js`의 `products` 배열
- 색상과 레이아웃: `style.css`

## 게시 전 확인
- 실제 농장/상품 사진 교체
- 전화번호 및 주문 채널 등록
- 가격, 수량, 배송, 교환·환불 정책 확인
- 사업자 정보, 통신판매업 신고 등 적용 법규 확인
- 산양삼 품질검사 및 생산이력 등 표시 내용 확인
- 이미지 및 방송 콘텐츠 사용 권한 확인

# 신농산삼약초농원 홈페이지 v5

GitHub Pages 다중 페이지 홈페이지 + 산양삼 구매 문의 기능.

- **배포:** 압축 해제 후 루트의 모든 파일 및 `assets/` 폴더를 GitHub 저장소 루트에 업로드
- **메일 연동:** `GoogleAppsScript/설치안내.md` 참조. Google Apps Script 웹 앱을 배포하고 `config.js`에 URL 입력해야 작동
- **수신 주소:** `rkdwnsgh2002@gmail.com` (Apps Script `RECIPIENT`)
- **문의 페이지:** `contact.html`
- **Analytics:** `config.js`에 GA4 측정 ID를 넣으면 동의 후 추적
- **주의:** 홈페이지 파일만 올리면 온라인 문의 전송은 활성화되지 않음
